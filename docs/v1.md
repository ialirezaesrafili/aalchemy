#  What is Aalchemy?

**Aalchemy** is a lightweight, zero-config PostgreSQL query monitoring tool for Node.js applications.

It is designed to give backend developers real-time visibility into how their application interacts with the database—without requiring complex setup, external services, or heavy observability platforms.

In its first version (v1), Aalchemy focuses on capturing all PostgreSQL queries executed in an application, grouping them by request, and detecting common performance issues such as N+1 query patterns and slow database operations.

The goal of Aalchemy is to help developers understand and improve database performance early in the development cycle, making backend systems easier to debug, optimize, and scale.

---

##  Core idea of v1

Instead of manually inspecting logs or integrating full observability stacks, Aalchemy provides:

- Automatic PostgreSQL query tracking  
- Request-level query grouping  
- Detection of repeated queries (N+1 patterns)  
- Identification of slow database operations  
- Immediate console-based performance insights  

---

##  Design philosophy

Aalchemy v1 is built around three core principles:

- **Zero configuration** — works immediately after installation  
- **Transparency** — exposes real database behavior per request  
- **Lightweight performance** — minimal overhead on application execution
