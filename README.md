#  Aalchemy

**Aalchemy** is a lightweight, zero-config PostgreSQL query monitoring tool for Node.js applications.

It helps backend developers instantly understand database performance by tracking queries, detecting N+1 patterns, and identifying slow database operations in real time.

##  What Aalchemy does (v1)

- Tracks all PostgreSQL queries automatically
- Groups queries per request
- Detects N+1 query patterns
- Detects slow queries
- Prints real-time performance logs in the console
